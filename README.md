## Projetos em destaque

### IA WhatsApp

Sistema desktop para atendimento automatizado em várias instâncias do WhatsApp, com respostas geradas por modelos de IA executados localmente via Ollama. A arquitetura tem três módulos: interface em CustomTkinter, API REST em FastAPI com SQLite e gateway em Node.js com Baileys. Inclui configuração de prompt e base de conhecimento por instância, limite de respostas por contato e versão executável para Windows.

Repositório: https://github.com/giancarlofrancozo/IA_WHATSAPP

### Sistema de gestão para pizzaria

Sistema para comandas de restaurantes e pizzarias, com interface web responsiva acessível pelo celular na rede Wi-Fi. Inclui módulo do garçom com mapa de mesas, meio a meio e bordas recheadas, tela da cozinha com atualização de status e módulo do caixa com pagamento parcial, cálculo de troco e fechamento de comandas. O backend usa API REST em FastAPI, SQLAlchemy e SQLite, com login e controle de acesso por nível (administrador e garçom).

Repositório: https://github.com/giancarlofrancozo/Gestao_pizzaria

Demonstração em vídeo: https://youtu.be/UFahEj4N4pg

### Bot de notas fiscais

Automação RPA com Playwright e Flask para emissão e processamento de notas fiscais eletrônicas, com navegação headless, captura de PDFs e validação de dados em CSV.

Repositório: https://github.com/giancarlofrancozo/bot-notas-fiscais

### Detector de duplicatas

Ferramenta em Python para detectar e remover registros duplicados em planilhas, com interface gráfica em CustomTkinter e distribuição como executável.

Repositório: https://github.com/giancarlofrancozo/-duplicate-detector

### Chatbot com IA local

Chatbot que usa modelos executados localmente com Ollama, com API em FastAPI.

Repositório: https://github.com/giancarlofrancozo/chatbot-ollama

### Dashboard de vendas

Análise de dados comerciais com SQL e Excel, com indicadores de conversão e de leads.

Repositório: https://github.com/giancarlofrancozo/Dashboard-Vendas-Excel-SQL
